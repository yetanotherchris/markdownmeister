MarkdownMeister privacy policy

Last updated: 2026-09-30.

MarkdownMeister is a desktop markdown editor. It is designed to work on files you choose on your own computer and to send nothing anywhere.

What the app collects

None. MarkdownMeister collects no personal data, no usage analytics and no telemetry, and it does not create an account. It has no advertising and no third-party tracking.

What the app accesses

  • Files and folders you explicitly open. The app reads and writes only inside the folder you open.
  • Your settings and recent-items list, stored locally on your computer.

The app does not transmit file contents or paths off your computer.

If you install from the Microsoft Store

Installing and updating through the Microsoft Store is handled by Microsoft. Microsoft may collect install and usage information under the Microsoft Privacy Statement. That data is controlled by Microsoft, not by MarkdownMeister.

This website

This page is served by GitHub Pages. The page itself sets no cookies. A small script on the main page asks GitHub's public releases API for the latest version number; that request does not include any information about you beyond what any web request carries.

Changes and contact

This policy may be updated; the date at the top reflects the latest change. Questions can be raised at github.com/yetanotherchris/markdownmeister/issues.
